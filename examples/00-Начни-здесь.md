# Шпаргалки под рукой

Это твой личный справочник по Linux и DevOps. Открывай его **Super + Ё**, находи нужное и возвращайся к работе той же комбинацией.

## Как добавить заметку

Положи `.md` файл в папку `~/Notes/cheatsheets`. Можно создавать вложенные папки: **Linux**, **Docker**, **Git**. Изменения появятся автоматически.

- Клик по заметке открывает её во вкладке.
- **Ctrl+K** — поиск по заголовкам, именам файлов и тексту.
- **Ctrl+Tab** — следующая открытая вкладка.
- **Ctrl+W** — открыть заметку в редакторе в обычном тайлинге.
- **Ctrl+N** — создать заметку прямо в Quickref, **Ctrl+S** — сохранить.
- **×** на вкладке — закрыть её.
- **Ctrl+E** — открыть исходный файл во внешнем редакторе.
- Кнопка **Копировать** забирает весь блок кода в буфер обмена.

## Шаблон заметки

````markdown
# Короткий вопрос или тема

Когда это нужно и что означает результат.

```bash
команда --аргумент
```

Что запомнить: один-два важных нюанса.
````

Вкладки и место чтения сохраняются. Твои заметки — обычные файлы: их можно редактировать любым редактором и хранить в Git.
