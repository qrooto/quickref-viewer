# Your reference, close at hand

Quickref Viewer keeps Markdown notes available while you work. Use it for study notes, checklists, recipes, and command references.

## Getting started

- Press **Ctrl+K** to search titles and filenames.
- Open a result to read it in a tab.
- Press **Ctrl+F** to find text in the current note.
- Press **Ctrl+N** to create a note, then **Ctrl+S** to save it.
- Press **Ctrl+E** to edit a note in your default Markdown editor.
- Press **?** for keyboard help.

Notes are ordinary files. Open tabs and reading positions are restored next time.

# Show available disk space in human-readable units.
