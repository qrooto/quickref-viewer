# Linux: куда смотреть

## Состояние службы

```bash
systemctl status nginx
journalctl -u nginx -b -n 100 --no-pager
```

`status` — текущее состояние и последние сообщения. `journalctl` — журнал: `-u` выбирает службу, `-b` — текущую загрузку, `-n 100` — последние 100 записей.

## Кто слушает порт

```bash
ss -ltnp
```

- `-l` — только слушающие сокеты.
- `-t` — TCP.
- `-n` — адреса и порты числами.
- `-p` — процессы; для чужих процессов могут потребоваться дополнительные права.

## Память и диски

```bash
free -h
df -h
du -sh ./каталог
```

`free` показывает память; смотри на **available**, а не только **free**. `df` показывает место на файловых системах, `du` — объём файлов в конкретном каталоге.

## Файлы и права

```bash
ls -lah
stat имя-файла
```

В строке `-rwxr-xr--` первый символ — тип файла, затем три группы прав: владелец, группа, остальные. `r` — чтение, `w` — запись, `x` — выполнение; для каталога `x` означает возможность прохода.
