# Omarchy: горячие клавиши

**Super** — клавиша Windows / Command. Здесь собраны сочетания из текущей настройки этого компьютера.

| Клавиши | Действие |
| --- | --- |
| Super + Ё | Показать / скрыть Quickref |
| Super + Ctrl + Shift + A | Запустить агента отдельным окном |
| Super + Enter | Терминал |
| Super + Shift + Enter | Браузер |
| Super + Space | Меню Omarchy |
| Super + K | Список горячих клавиш |
| Ctrl + Space | Сменить язык ввода |
| Super + C / V / X | Копировать / вставить / вырезать |

Сочетания могут меняться в пользовательском конфиге:

```text
~/.config/hypr/bindings.lua
```
